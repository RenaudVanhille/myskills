# diagram-brief

> Statut : squelette. Contenu à écrire à l'étape 3.

## Ce que fera ce skill

Fournir la grille de décision utilisée par l'agent `diagram-coordinator` :

| Contexte | Format |
| --- | --- |
| Public non technique, atelier, vue d'ensemble | Excalidraw |
| Architecture logicielle (contexte, conteneurs, composants) | C4 (LikeC4 ou Mermaid C4) |
| Documentation dans le dépôt ou Obsidian | Mermaid |
| Word, PowerPoint, Confluence | draw.io |

Ainsi que les questions à poser quand le contexte ne suffit pas.
